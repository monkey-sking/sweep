AI 开发者磁盘缓存与本地数据盘点工具：扫描 AI 工具目录、汇总磁盘占用，并提供独立的会话清理工具。当前代码来自可运行原型，适合继续开发；不会自动删除文件。

## 功能

- 扫描常见 AI 工具和模型缓存目录
- 生成可视化磁盘占用报告
- 管理本地 AI 会话数据
- 提供 Windows 启动脚本

## 使用

```bash
python sweep_scan.py
python server.py
```

Windows 下可运行 `start_sweep.bat`。

仓库不包含个人扫描结果、机器路径示例或凭据；请勿把扫描产物提交回仓库。
